# SphereScript Language Reference & Documentation Wiki (SphereWiki-X)

Welcome to the definitive SphereScript language reference and developer toolkit for **SphereServer X** (Source-X).

This documentation is modeled after the community [SphereWiki](https://wiki.spherecommunity.net/index.php?title=Main_Page), extended with Source-X engine specifications, and structured to power both human scripters and autonomous AI agents / MCP servers.
